# Neon Dodge

Game arcade sederhana berbasis HTML5 Canvas dan Vanilla JavaScript. Hindari balok merah yang jatuh dan raih skor tertinggi!

## Fitur
- Kontrol responsif (`A`/`D` atau `Arrow Left`/`Arrow Right`)
- Tingkat kesulitan progresif (kecepatan jatuh meningkat seiring bertambahnya skor)
- Penyimpanan High Score otomatis menggunakan `localStorage`

## Cara Menjalankan
Buka file `index.html` langsung di browser atau akses melalui GitHub Pages.
